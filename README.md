# SpecDriven Project Template

Шаблон для быстрого старта проектов с **SpecDriven** подходом — разработкой, управляемой спецификациями.

## Установка

```bash
# Зависимости не требуются — это шаблон проекта
```

## Инициализация

```bash
# Инициализируй новый проект
инициализируй проект для {описание}
```

## Использование

```bash
# Напиши спецификацию
создай спецификацию для {описание функциональности}

# Реализуй по спецификации
реализуй спецификацию {spec-name}

# Проверь соответствие
аудит спецификаций для {spec-name}
```
