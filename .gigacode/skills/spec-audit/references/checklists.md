# Checklists — Spec Audit

## Чек-лист аудита

### 1. Размер и структура

- [ ] SKILL.md ≤ 200 строк
- [ ] Все файлы references/ ≤ 200 строк
- [ ] Контент разделён на логические файлы
- [ ] Нет дублирования между SKILL.md и references/

### 2. Кросс-ссылки

- [ ] Все ссылки на гайдлайны проекта рабочие
- [ ] Пути к файлам указаны относительно корня проекта
- [ ] Нет ссылок на несуществующие файлы
- [ ] Нет ссылок с лишними префиксами (docs/, и т.д.)

### 3. Дублирование

- [ ] Нет дублирования с guidelines/
- [ ] Статусы спецификаций — ссылка на specification-guidelines.md
- [ ] NEEDS_CLARIFICATION — ссылка на specification-guidelines.md
- [ ] Правила реализации — ссылка на implementation-guidelines.md

### 4. Фронтматтер

- [ ] name — уникальное имя скилла
- [ ] description — содержит триггеры и краткое описание

### 5. Согласованность

- [ ] Все ссылки в SKILL.md ведут на существующие файлы в references/
- [ ] Разделы SKILL.md соответствуют файлам в references/
- [ ] Workflow описан в references/workflows.md
