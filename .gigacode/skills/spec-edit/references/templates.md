# Templates -- Spec Edit

See [SKILL.md](../SKILL.md) -- overview and scenarios.

## Формат отчёта пользователю

```
## Спецификация: {spec-id}

### Статус
- Статус: `{DRAFT | IMPLEMENTED_STABLE | IMPLEMENTED_NEED_WORK}` (во фронтматтере YAML)
- Новый файл: `specs/{domain}/{file}.md`
- ID: `{spec-id}`
- Секций: {N}

### Уточняющие вопросы
- Уточнено: {что уточнил пользователь}
- NEEDS_CLARIFICATION: {что осталось неясным}
- Допущения: {что было додумано, с пометкой "ДОПУЩЕНИЕ"}

### Связанные спецификации
- `specs/{domain}/{related}.md` — {как связано}

### Чек-лист качества
- [x] Требование однозначно
- [x] Поведение можно проверить тестами
- [x] Нет противоречий с другими specs
- ...

### Готовая спецификация
{полный текст spec}
```

## Шаблоны спецификаций

### Шаблон новой спецификации

```markdown
# {ID}-spec — {Название}

## Purpose
{Что и зачем делает функциональность. 1-2 предложения.}

## Preconditions
{Условия, необходимые для выполнения.}
- { precondition 1 }
- { precondition 2 }

## Inputs
{Входные данные и ограничения.}

### {Сущность 1}
| Поле | Тип | Описание |
|---|---|---|
| { field } | { type } | { description } |

### {Сущность 2}
...

## Behavior
{Подробное описание ожидаемого поведения.}

### {Сценарий 1}
1. { шаг 1 }
2. { шаг 2 }
3. { шаг 3 }

### {Сценарий 2}
...

## Business rules
{Правила и ограничения.}
- { rule 1 }
- { rule 2 }

## Errors
| Ситуация | Исключение | Поведение |
|---|---|---|
| { situation } | { exception } | { behavior } |

## Acceptance criteria
- [ ] { criterion 1 }
- [ ] { criterion 2 }
- [ ] { criterion N }

## Examples
{Примеры поведения, если они помогают устранить неоднозначность.}
```

### Шаблон обновления спецификации

```markdown
# {ID}-spec — {Название}

## Purpose
{Те же purpose, что в оригинале}

## Changes from previous version

### Добавлено
- { что добавлено }
- { что добавлено }

### Изменено
- { что изменено: было → стало }
- { что изменено: было → стало }

### Удалено
- { что удалено }

## { Остальные секции — обновить в соответствии с изменениями }
...
```
