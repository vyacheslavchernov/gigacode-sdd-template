# Checklists — Skill Audit

Чек-листы для аудита скиллов.

See [`SKILL.md`](../SKILL.md) -- overview and scenarios.

---

## Чек-лист аудита скилла

**ПЕРЕД сообщением пользователю -- проверь каждый пункт:**

```
Аудит скилла {skill-name}:
- [ ] SKILL.md <= 200 строк
- [ ] Нет дублирования контента из references/* (и наоборот)
- [ ] Нет дублирования контента из docs/, guidelines/, GIGACODE.md
- [ ] Большие логические блоки вынесены в references/ (workflow, examples, templates)
- [ ] SKILL.md содержит только ссылки на references/* + ёмкое описание
- [ ] Все файлы references/* ссылаются обратно на SKILL.md
- [ ] Нет противоречий между файлами скилла
- [ ] Фронтматтер (YAML) консистентен во всех файлах
```

---

## Чек-лист агентного workflow

**ПЕРЕД запуском аудита -- убедись в каждом пункте:**

### Подготовка
```
- [ ] Определён целевой скилл: {skill-name}
- [ ] Путь к скиллу известен: .gigacode/skills/{skill-name}/
- [ ] Промты для суб-агентов прочитаны: references/prompts.md
```

### Запуск суб-агентов
```
- [ ] Запущен агент "Сборка списка файлов скилла"
- [ ] Запущены параллельно: агент "Проверка дублирования (внутренняя)" + агент "Проверка дублирования (внешняя)"
- [ ] Запущен агент "Проверка ссылок на docs/guidelines"
- [ ] Запущен агент "Проверка согласованности"
- [ ] Получены отчёты от всех агентов в структурированном формате
```

### Генерация отчёта
```
- [ ] Измерен размер SKILL.md самостоятельно (не через агента)
- [ ] Объединены результаты всех суб-агентов в итоговый отчёт
- [ ] Отчёт соответствует формату из references/templates.md
- [ ] Отчёт предоставлен пользователю
```

### Рефакторинг (если запрошен)
```
- [ ] Рефакторинг декомпозирован на атомарные шаги
- [ ] Каждый шаг делегирован отдельному суб-агенту
- [ ] Шаги выполнены последовательно (не параллельно)
- [ ] Получены отчёты Refactoring Report от каждого агента
- [ ] Проведён полный аудит заново (Шаг 1-7)
- [ ] Итоговый отчёт предоставлен пользователю
```

## Чек-лист качества отчётов суб-агентов

**ПЕРЕД использованием отчёта -- проверь каждый пункт:**

```
- [ ] Отчёт содержит секцию Summary с количественными метриками
- [ ] Отчёт содержит секцию Issues с конкретными проблемами
- [ ] Каждая проблема имеет контекст (фрагмент текста)
- [ ] Каждая проблема имеет рекомендацию по исправлению
- [ ] Если проблем нет -- секция Clean заполнена
- [ ] Формат отчёта соответствует шаблону из templates.md
- [ ] Промт для агента был корректно сформирован из prompts.md
```
