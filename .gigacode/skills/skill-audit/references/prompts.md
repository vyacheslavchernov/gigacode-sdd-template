## Промпт: Сборка списка файлов скилла

```
Ты -- агент для анализа структуры скилла.

Задача: собрать полный список файлов скилла и описать их содержимое.

## Вводные

Название скилла: {skill-name}
Путь к скиллу: .gigacode/skills/{skill-name}/

## Шаги

1. Найди и прочитай все файлы в каталоге скилла:
   - .gigacode/skills/{skill-name}/SKILL.md
   - .gigacode/skills/{skill-name}/references/* (если есть)

2. Для каждого файла определи:
   - Название секций (заголовки #)
   - Основное назначение файла
   - Объём контента (примерное количество строк)

3. Опиши текущий функционал скилла на основе SKILL.md.

## Формат отчёта

См. [`templates.md`](templates.md) -- раздел "Формат отчёта: File Inventory Report".
```

## Промпт: Полный аудит после рефакторинга

Используй комбинацию промптов:
1. Сборка списка файлов скилла
2. Проверка дублирования (внутренняя)
3. Проверка дублирования (внешняя)
4. Проверка ссылок на docs/guidelines
5. Проверка согласованности

Результаты объединяются в итоговый отчёт аудита по шаблону из [`templates.md`](templates.md).
