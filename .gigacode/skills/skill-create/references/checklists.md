# Checklists -- Skill Create

See [`SKILL.md`](../SKILL.md) -- overview and scenarios.

## Создание скилла

### Базовые проверки

- [ ] Название скилла уникально (нет в `.gigacode/skills/`)
- [ ] Название в стиле snake_case (например: `skill-audit`)
- [ ] SKILL.md создан в `.gigacode/skills/{skill-name}/SKILL.md`
- [ ] Фронтматтер консистентен:
  - [ ] `name` — уникальное название
  - [ ] `last_updated` — дата в формате YYYY-MM-DD
  - [ ] `scope` — `skill`
  - [ ] `description` — краткое описание + триггеры
- [ ] Есть заголовок `# {Skill Name}`
- [ ] Есть краткое описание назначения (1-2 предложения)
- [ ] Есть секция `## Правила проекта` со ссылками на guidelines/
- [ ] Есть секция `## Сценарии` с командами-триггерами
- [ ] Есть секция `## Уточняющие вопросы`
- [ ] Есть секция `## Critical Rules` с ALWAYS/NEVER
- [ ] Зарегистрирован в GIGACODE.md (`## Доступные скиллы`)

### Структура references/ (опционально)

- [ ] Каталог `references/` создан (если скилл продвинутый)
- [ ] `references/workflows.md` — детальные шаги workflow
- [ ] `references/examples.md` — примеры good/bad
- [ ] `references/templates.md` — шаблоны файлов
- [ ] `references/checklists.md` — чек-листы
- [ ] Все файлы references/ имеют заголовок `# {Section} -- {Skill Name}`
- [ ] Все файлы references/ ссылаются на SKILL.md
- [ ] SKILL.md ссылается на все файлы references/

### Качество контента

- [ ] SKILL.md <= 200 строк
- [ ] Нет дублирования контента между SKILL.md и references/
- [ ] Нет дублирования контента с guidelines/, docs/
- [ ] Все ссылки рабочи (не битые)
- [ ] Терминология согласована во всех файлах
- [ ] Триггеры на русском и английском (если уместно)

### Аудит

- [ ] Запущен skill-refactor через суб-агента
- [ ] Получен результат аудита
- [ ] Критические замечания исправлены
- [ ] Цикл автофиксов завершён (PASS или 3 итерации)
- [ ] Результат аудита предоставлен пользователю

## Аудит скилла (для skill-refactor)

### Размер

- [ ] SKILL.md <= 200 строк
- [ ] Если > 200 — контент перенесён в references/

### Дублирование

- [ ] Нет дублирования между SKILL.md и references/
- [ ] Нет дублирования с guidelines/, docs/, GIGACODE.md
- [ ] Нет дублирования между файлами references/

### Согласованность

- [ ] Фронтматтер консистентен во всех файлах
- [ ] Кросс-ссылки работают (SKILL.md <-> references/)
- [ ] Терминология согласована
- [ ] Нет противоречий в шагах workflow

### Ссылки

- [ ] Все ссылки на guidelines/ актуальны
- [ ] Все ссылки на другие скиллы актуальны
- [ ] Все ссылки на references/ ведут на существующие файлы

### Регистрация

- [ ] Скилл зарегистрирован в GIGACODE.md
- [ ] Описание в GIGACODE.md соответствует SKILL.md
