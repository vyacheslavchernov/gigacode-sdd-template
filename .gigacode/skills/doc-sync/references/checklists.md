# Checklists — Doc Sync

Чек-лист завершения обновления документации.

Обзор и сценарии — в [`SKILL.md`](../SKILL.md).

---

## Чек-лист завершения doc-sync

**Перед сообщением пользователю о завершении doc-sync проверь каждый пункт и отметь:**

```
Документация обновлена:
- [ ] docs/modules/{изменённый_модуль}.md
- [ ] docs/packages/{изменённый_пакет}/*.md
- [ ] README.md в корне каждого изменённого модуля
- [ ] docs/architecture.md (если изменилась структура/зависимости/нужно отразить новые архитектурные решения)
- [ ] docs/README.md (если изменилась навигация/структура)
- [ ] docs/testing/*.md (если изменились тесты)
- [ ] specs/{domain}/{spec-id}-spec.md (если изменилось поведение системы, описанное в спецификациях)
- [ ] GIGACODE.md (если изменилась структура каталогов, гайдлайны, скиллы или команды)
```

**Если хотя бы один пункт не отмечен — не завершай doc-sync. Завершить можно только после выполнения всех пунктов!**
