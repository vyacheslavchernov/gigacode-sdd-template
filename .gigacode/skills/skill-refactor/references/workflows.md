# Workflows — Skill Refactor

Детальные шаги аудита и рефакторинга скиллов.

See [`SKILL.md`](../SKILL.md) — overview and scenarios.

---

## Проверка дублирования

### SKILL.md ↔ references/*

1. Прочитай SKILL.md и все файлы references/
2. Для каждой секции SKILL.md проверь:
   - Есть ли аналогичный контент в references/?
   - Если да -- SKILL.md должен содержать только ссылку
   - Если нет -- контент должен остаться в SKILL.md (если компактный) или быть перенесён
3. Для каждого файла references/ проверь:
   - Есть ли дублирование контента в другом файле references/?
   - Если да -- объединить

### Ссылки на docs/ и guidelines/

1. Проверь, не дублирует ли SKILL.md или references/ контент из:
   - `guidelines/*.md` -- гайдлайны проекта
   - `docs/architecture.md` -- архитектура
   - `GIGACODE.md` -- структура проекта
2. Если контент есть в guidelines/ -- оставить только ссылку в SKILL.md
3. Пример:
   ```markdown
   Bad: полный текст guidelines/documentation-guidelines.md в SKILL.md
   Good: **ВСЕГДА** следуй [`guidelines/documentation-guidelines.md`](../../guidelines/documentation-guidelines.md)
   ```

## Workflow аудита

### Шаг 1: Сборка списка файлов скилла

Найди все файлы скилла:

```bash
# Найти все директории скиллов
ls .gigacode/skills/

# Для каждого скилла найти все файлы
ls .gigacode/skills/{skill-name}/
ls .gigacode/skills/{skill-name}/references/  # если есть
```

### Шаг 2: Измерение размера SKILL.md

```bash
wc -l .gigacode/skills/{skill-name}/SKILL.md
```

**Критерий:** <= 200 строк. Если больше -- рефакторить.

### Шаг 3: Проверка дублирования

Для каждого скилла:

1. Прочитай SKILL.md
2. Прочитай все файлы references/
3. Для каждой секции SKILL.md проверь наличие аналога в references/
4. Для каждого файла references/ проверь наличие аналога в SKILL.md
5. Зафиксируй дубликаты

### Шаг 4: Проверка ссылок на docs/ и guidelines/

1. Извлеки все ссылки на `guidelines/`, `docs/`, `GIGACODE.md` из SKILL.md и references/
2. Прочитай целевые файлы
3. Проверь: не дублирует ли скилл контент из этих файлов?
4. Если дублирует -- заменить на ссылку

### Шаг 5: Проверка согласованности

1. Проверь фронтматтер во всех файлах
2. Проверь кросс-ссылки (SKILL.md -> references/ -> SKILL.md)
3. Проверь консистентность терминологии
4. Проверь, что нет противоречий в шагах workflow

### Шаг 6: Генерация отчёта

См. [`references/templates.md`](templates.md) -- формат отчёта.

### Шаг 7: Применение рефакторинга (по согласованию)

Если пользователь запросил рефакторинг -- примени изменения:

1. Создай `references/` если нет
2. Перенеси большие секции в соответствующие файлы
3. Обнови SKILL.md -- оставь только ссылки
4. Добавь кросс-ссылки
5. Проверь результат (Шаг 3-5 повторно)
